## 1. 全站设计系统对齐基准

所有改造均须严格遵循既有的**暖纸质学术人文风（Academic Humanism）**：

1. **色彩令牌**：
   - 画布背景：`--canvas: #f2efe7`（带 2.5% SVG 纸浆微噪点）
   - 卡片背景：`--paper: #fbfaf6` / 浮层白 `#ffffff`
   - 线框描边：`--line: #dcd9d0` / `--line-soft: #e9e6de`
   - 主墨色文字：`--ink: #172129` / `--ink-soft: #536067` / `--muted: #8b918f`
   - 语义强调色：`--coral: #ef846d`（警示/强调）、`--blue: #74a4b5`（进行/信息）、`--green: #7cac85`（完成/通过）、暖黄 `#e8b277`（部分得分）
2. **排版规范**：
   - 标题与核心大数字：`Noto Serif SC`（`--serif`）
   - 标签与正文：系统无衬线字体（`--sans`）
3. **空间与动效**：
   - 卡片大圆角 `16px`，小卡片 `12px`，控件药丸 `999px`
   - 投影采用柔和弥散的 `0 4px 20px rgba(35, 42, 44, 0.035)`，严禁高饱和霓虹发光与刺眼深黑阴影

## 2. 详细改造需求清单

### P0 核心状态逻辑

#### REQ-P0-1 「一刷」与「二刷」状态机联动与约束
*   **问题分类**：信息架构 / 状态机逻辑
*   **当前代码**：
    - `app/study-dashboard.tsx:3551-3569`（真题卡片复选框）
    - `app/study-dashboard.tsx:3696-3714`（模拟卷卡片复选框）
    - `app/study-dashboard.tsx:1097-1110`（`togglePaperSecondRound`）
*   **现状缺陷**：
    - `paper.completed` 与 `paper.secondRound` 相互独立，允许用户在未勾选一刷时直接勾选二刷；
    - 取消一刷勾选时，二刷依然保持勾选；卡片呈现“未做 + 二刷已完成”的逻辑荒谬态。
*   **改造要求**：
    1. **正向联动**：当勾选「二刷」且当前 `paper.completed` 为 false 时，自动将 `completed` 设为 `true`，并联动补齐 `completedAt`（为今天日期）；页面给出轻量反馈提示：“已同步标记一刷完成”。
    2. **逆向级联**：当用户取消勾选「已做」（一刷置为 false）时，若该卷 `secondRound` 为 true，自动联动将其置为 `false` 并清空 `secondRoundAt`。
    3. **可选 UI 约束**：未完成一刷前，「二刷」复选框保持半透明（opacity: 0.65）并显示 `title="完成一刷后方可标记二刷"`，点击时直接触发上述正向联动逻辑。

### P1 视觉层级与交互规范

#### REQ-P1-1 外层容器解构：消除双重卡片嵌套与空间侵蚀
*   **问题分类**：布局结构 / 空间体系
*   **当前代码**：
    - `app/globals.css:3417-3426`（`.sprint-section`）
    - `app/study-dashboard.tsx:3481`（`<section className="sprint-section">`）
*   **现状缺陷**：
    - `.sprint-section` 本身被设计成一个包含 `border`、`border-radius: 16px`、`background: var(--paper)`、`box-shadow` 以及 `padding: 20px` 的大卡片；
    - 内部的 `.sprint-bento-card` 也是完全独立的卡片，产生典型的“大卡片套小卡片（Card inside Card）”嵌套；
    - 外层的 `padding: 20px` 在宽度 ≤1024px 时浪费了 40px 的有效横向宽度，使内部 280px 卡片提前产生挤压。
*   **改造要求**：
    1. **解构外层容器**：将 `.sprint-section` 弱化为纯结构容器（背景改为 `transparent`，移除 `border` 和 `box-shadow`，移除左右 20px padding）。
    2. **标题区优化**：保留 `.sprint-section-header`，使其直接附着在内容顶部，底部保留 1px `var(--line-soft)` 分隔虚线或微弱底边。
    3. **通透感回归**：让内部 `.sprint-bento-card` 直接呼吸在 `--canvas` 背景上，与全站 `task-panel` 与 `hero-card` 的平铺模式对齐。

#### REQ-P1-2 完成态视觉重塑：废除黑底药丸，归正底色与焦点
*   **问题分类**：视觉层次 / 色彩语义
*   **当前代码**：
    - `app/globals.css:3522-3525`（`.sprint-bento-card.completed`）
    - `app/globals.css:3550-3554`（`.sprint-bento-card.completed .bento-year-pill`）
*   **现状缺陷**：
    - 卡片标记为已完成时，其年份药丸标签变成纯黑底白字（`background: var(--sidebar-soft); color: #f2efe7;`），成为卡片最刺眼的焦点；
    - 已完成卡片底色变成暖纸色，未完成卡片却是亮纯白，形成“已做沉入背景、未做高亮浮起”的色彩反转。
*   **改造要求**：
    1. **废除黑底反色年份药丸**：`.sprint-bento-card.completed .bento-year-pill` 移除黑底设置，采用柔和绿调边框与微量灰绿背景（如 `background: rgba(124, 172, 133, 0.12); color: var(--ink); border-color: rgba(124, 172, 133, 0.35);`）。
    2. **底色与完成态边框**：保留左侧 3.5px `var(--green)` 条形微标，卡片背景维持全站统一的暖白底色，悬停时使用 `translateY(-2px)` + 阴影加深表达物理浮起，不再使用背景跳色。
    3. **视觉焦点归位**：使视线第一落点回归到具体的成绩（Coral 衬线数值）与对错热力图上。

#### REQ-P1-3 答题卡交互收敛：热力图主体纯展示，仅点击【答题卡】按钮呼出弹窗
*   **问题分类**：交互明确性 / 可意会性（Affordance）
*   **当前代码**：
    - `app/study-dashboard.tsx:1546-1616`（`renderBentoHeatmap`）
    - `app/globals.css:3800-3850`（`.bento-mini-heatmap`）
*   **现状缺陷**：
    - 当前整块热力图被包裹为一个外层 `<button>`，点击热力图空白处、点击小圆点、点击标签均会无差别触发弹窗；
    - 视觉上小圆点有独立悬停反馈，内部还嵌套了一个白色伪按钮 `<span className="mini-heatmap-open-btn">答题卡</span>`，导致用户误以为每个点可单独点选，造成误触与认知断裂。
*   **改造要求**：
    1. **容器标签变更**：将 `.bento-mini-heatmap` 从 `<button>` 改为语义化的 `<div>` 容器，移除外层容器直接绑定的 `onClick`。
    2. **明确呼出入口**：在热力图头部左侧保留或强化 `<button type="button" className="mini-heatmap-open-btn">答题卡</button>`，**仅当用户显式点击此按钮时，才触发** `setActivePaperQuestionModalId(paper.id)` 唤出答题卡弹窗。
    3. **热力图主体展示化**：热力图各圆点与题号方块转为纯粹的“只读做题表现看板”，移除圆点上的误导性交互行为（保留基础 title 提示或优化为更清晰的表现，触屏设备不再误触发弹窗）。

#### REQ-P1-4 窄屏移动端排版保护：Header 与工具栏防挤压折行
*   **问题分类**：响应式布局 / 边界保护
*   **当前代码**：
    - `app/globals.css:3528-3536`（`.bento-card-top`）
    - `app/globals.css:3588-3597`（`.bento-top-controls`）
    - `app/globals.css:4728-4737`（`.sprint-toolbar` 移动端样式）
*   **现状缺陷**：
    - 真题卡片顶部为单行 Flex（年份 + 分数 + 已做 + 二刷），内容总宽度达 240px，在 280px 卡片内余量不足。遇到大字号或多位分数值时，复选框极易掉入第二行，造成各卡片高度不一、网格犬牙交错；
    - 在 375px 视口下，工具栏选项带有长计数（如“历年真题 (16)”）容易单行换行撑高。
*   **改造要求**：
    1. **卡片 Header 弹性规划**：
       - 为 `.bento-top-controls` 设置稳定的弹性换行行为，或者为真题卡片也规划清晰的排版基线，保证分数与复选框组合紧凑稳固；
       - 设置卡片最小高度基准，防止因单卡折行造成网格跳动。
    2. **移动端工具栏紧凑适配**：
       - 在 `@media (max-width: 640px)` 下，简化或收敛药丸文字，或将 padding 调整至 `5px 8px`，确保主流 360px~390px 屏幕下单行排布整齐不溢出。

### P2 细节体验打磨

#### REQ-P2-1 模拟卷里程碑进度条收敛为全站温和单色/双色渐变
*   **问题分类**：视觉一致性 / 调性统一
*   **当前代码**：
    - `app/globals.css:3283-3286`（`.endless-fill`）
*   **现状缺陷**：
    - 模拟卷的里程碑进度条使用了 `linear-gradient(90deg, var(--blue), #e8b277, var(--coral))` 蓝->黄->粉三色高饱和渐变，呈现科技仪表盘与游戏血条感，与全站温和的学术纸面氛围冲突。
*   **改造要求**：
    - 将 `.endless-fill` 的渐变收敛为全站规范色，与真题进度条保持同系质感：
      `background: linear-gradient(90deg, var(--blue), var(--coral));` 或单一低饱和高质感色调，剔除突兀的中间黄色断层。

#### REQ-P2-2 完成日期选择器平滑过渡：消除 Footer 布局抖动
*   **问题分类**：动效微交互 / 视觉稳定性
*   **当前代码**：
    - `app/study-dashboard.tsx:3577-3585`（真题 Footer 日期渲染）
    - `app/study-dashboard.tsx:3722-3730`（模拟卷 Footer 日期渲染）
*   **现状缺陷**：
    - 未完成时底部左侧渲染 `null`，勾选已做后突然挂载 `<EditableDate />`，直接横向顶推右侧日志按钮，造成卡片底部的瞬间跳动（Layout Shift）。
*   **改造要求**：
    - 为 `.bento-footer-left` 设置固定或弹性占位基准；
    - 在挂载 `<EditableDate />` 时增加平滑的渐现动画（如 `animation: fadeIn 0.18s ease-out`），使日期的出现自然顺畅，无生硬位移。
