# 408 学习目录：页面紧凑化与计划日期

## 目标

在保留当前视觉风格和章节折叠交互的基础上，让用户进入页面后能看到更多目录内容，并把“计划完成时间”纳入每个小节的最小记录单元。

## 需求范围

### 视觉与布局

1. 压缩顶部区域：进度卡片和当前学习卡片降低高度，减少页面首屏占用。
2. 进度说明改为“学完 X / Y 小节，复习 X / Y 小节”。
3. 当前学习卡片只显示小节编号和小节名称，不再显示所属章节。
4. 缩窄左侧栏至约 200px；保留深色背景、当前科目背景色和左侧短线标记，缩小科目进度条。
5. 目录小节行压缩到约 44–48px，减少纵向滚动。

### 小节状态与日期

每个小节按以下顺序展示：

```text
1.3 操作系统的运行环境    计划 08/02    □ 学完    □ 复习
```

- 未完成状态只显示复选框和文字，不显示空日期输入框。
- 勾选“学完”或“复习一遍”时自动填写当天日期。
- 已完成日期以普通文字显示，点击日期文字后才进入日期编辑状态；失焦或回车保存。
- “复习一遍”在“学完”之前不可操作；取消“学完”同时清除复习状态及两者的完成日期。
- 计划日期可编辑。计划日期为空时显示“计划未设置”，不参与逾期判断。

### 计划日期与状态色

- `plannedAt` 保存为 `YYYY-MM-DD`。
- 对尚未学完的小节：计划日期为今天或未来 2 天内显示橙色，早于今天显示红色。
- 已学完的小节计划日期使用低对比度样式，不显示逾期警告。
- 章节卡片根据小节计划日期显示计划区间，例如“计划：8月1日—8月3日”；没有计划日期时显示“计划未设置”。
- 操作系统使用已有的一周主线安排计划日期；数据结构和计算机组成原理保留空计划日期，避免虚构历史计划。

## 数据设计

在 `Section` 增加可选字段：

```ts
plannedAt?: string;
```

在本地存储的每节进度中增加：

```ts
plannedAt: string;
```

沿用现有 `408-section-progress-v1` 键，并兼容旧数据：旧记录缺少 `plannedAt` 时回退到目录默认值。

## 实施文件

- `app/data/books.ts`：补充操作系统计划日期，并保留三本书完整目录。
- `app/study-dashboard.tsx`：压缩摘要信息、移除章节副标题、加入计划日期和可点击完成日期编辑器。
- `app/globals.css`：调整侧栏、摘要卡片、章节行和日期状态样式。
- `README.md`：同步本地预览与计划日期行为说明。

## 验收标准

- 页面首屏能看到压缩后的顶部摘要和至少更多于当前数量的小节行。
- 章节默认收起；展开后每行只出现计划日期、学完、复习三个状态区域。
- 未完成状态没有长期显示的日期输入框；已完成日期点击后才出现编辑控件。
- 计划日期能被修改，临近日期橙色、逾期日期红色，完成后不再显示警告色。
- 切换三本书、刷新页面后，目录和本地状态均正确保留。
- `npm run build` 通过；本次不创建或更新线上预览。
