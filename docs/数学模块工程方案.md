# 数学模块接入方案

## 目标

在不复制页面、不新建第二套进度逻辑的前提下，把现有学习看板扩展为两个顶层领域：`408` 与 `数学`。数学领域包含高等数学和线性代数，继续复用章节折叠、小节学习/复习、计划日期、总体进度和云端同步。

## 信息架构

```text
学习进度
├─ 408
│  ├─ 数据结构
│  ├─ 计算机组成原理
│  ├─ 操作系统
│  └─ 计算机网络
└─ 数学
   ├─ 高等数学
   └─ 线性代数
```

- 顶部右侧增加 `408 / 数学` 分段切换器。
- 左侧栏仅显示当前领域的科目，避免数学加入后侧栏过长。
- 切换领域时默认进入该领域上次查看的科目；首次进入数学时显示高等数学。
- 章节目录、进度卡、本周节奏和同步状态保持同一套组件与交互。

## 数据设计

在现有 `Book` 上增加领域字段：

```ts
type StudyArea = "408" | "math";

type Book = {
  area: StudyArea;
  // 其余字段沿用现有结构
};
```

数学科目继续通过 `makeBook` 创建，沿用全局唯一的小节 ID：

- 高等数学：`advanced-math-*`
- 线性代数：`linear-algebra-*`

现有本地存储键、D1 表和 API 均以小节 ID 为索引，因此不需要迁移数据库，也不会影响现有 408 进度。

## 目录映射

- 高等数学按 `content/content.md` 中的 8 章、23 个小节录入，每章末尾增加一个 `题目练习` 小节。
- 线性代数按 4 章、10 个小节录入，每章末尾增加一个 `题目练习` 小节。
- 数学内容默认未开始、计划日期为空。

## 交互细节

1. 顶部领域切换只改变可见科目和当前目录，不清空任何进度。
2. 左侧科目按钮继续负责高数/线代或四门 408 科目之间切换。
3. 总进度纳入数学与 408 的全部小节；当前科目进度只统计所选科目。
4. 切换领域或科目时收起已展开章节，避免保留无效展开状态。
5. 桌面端和移动端均保留领域切换器；移动端使用更紧凑的分段按钮。

## 实施文件

- `app/data/books.ts`：增加领域类型和数学目录。
- `app/study-dashboard.tsx`：增加领域状态、顶部切换与左侧过滤。
- `app/globals.css`：增加分段切换器样式及响应式规则。
- `app/layout.tsx`、`README.md`：更新产品描述和目录来源。
- `content/content.md`：作为包含 408 与数学的统一目录原稿。

## 验收标准

- 顶部可在 `408` 与 `数学` 间切换。
- 数学侧栏只显示高等数学、线性代数；408 侧栏只显示原四门科目。
- 高数显示 8 章、23 小节；线代显示 4 章、10 小节，每章均可单独记录 `题目练习` 进度。
- 数学的勾选、日期、计划日期与云端同步行为和 408 一致。
- 切换领域、科目及刷新后数据不互相覆盖。
- TypeScript、ESLint 与生产构建全部通过。
