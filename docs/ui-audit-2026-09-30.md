# 前端视觉审查问题清单（2026-09-30）

## 审查范围

在实际运行的页面中查看了学习进度、套卷冲刺、今日、复习课表、数据分析和设置六个主页面的桌面视图（1265 × 720）与手机视图（390 × 844），并检查了答题卡和学习日志编辑器。审查以真实页面渲染、展开状态和已有学习数据为依据，没有改动学习记录。

## 问题与整改

| 页面 | 观察到的问题 | 整改 |
| --- | --- | --- |
| 学习进度 · 桌面 | 在约 1265px 窗口，展开章的标题与新学、复习信息分两行，目录显得松散。 | 将单行布局的适用宽度扩展到 1121px 以上；更窄的桌面仍保留两行布局。 |
| 今日 · 桌面 | 空的今日任务卡沿用任务列表高度，留下大片无信息区域。 | 空状态卡按内容收紧，非空任务卡继续显示可滚动任务列表。 |
| 套卷冲刺 · 桌面 | 约 1265px 宽度仍显示三列试卷卡，答题点阵与操作区域过密。 | 卡片最小宽度提高到 360px，桌面点阵和标签略放大。 |
| 复习课表 · 手机 | 工具栏折成多行，占用较多首屏空间；从今日页进入时显示的周次可能不同。 | 工具栏改为紧凑网格和短标签，打开时先显示当前周；补齐第 25 周的选择项，并将课表加入手机“更多页面”。 |
| 设置 · 手机 | 本地备份行过窄，“恢复”“删除”按钮文字挤成竖排。 | 信息和操作分层，按钮保持横排且保留触控高度。 |

手机端进度和冲刺首页、数据分析概览、答题卡与日志编辑器未发现需要重构的布局问题，因此保留原有结构。

## 验证

在本地运行版本中再次查看上述问题视图，确认章节信息同排、空任务卡收紧、试卷卡改为两列、手机课表默认当前周且工具栏更短、备份按钮横排。`npm run typecheck`、`npm run lint`、`npm test`（70 项）和 `npm run build` 均通过。
