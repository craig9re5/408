# Atlas 考研备考空间

面向计算机 408 统考、考研数学、英语与政治的个人备考看板：管理知识点推进、每日任务、复习课表、套卷模考与学习日志。

线上地址：<https://study.craig9re5.workers.dev>（访问码登录）

---

## 设计概览

- **视觉**：暖米纸底色（`--paper`）+ 深青墨侧栏（`--sidebar`）+ 珊瑚强调色（`--coral`），标题使用自托管的 Noto Serif SC 可变字体。纯原生 CSS，不依赖 UI 组件库。
- **设计令牌**：颜色统一由 `app/globals.css` 中的语义令牌提供（`--blue-*`、`--green-*`、`--coral-*`、`--ochre-*`、`--slate-*`、课表主题 `--theme-*`、作答状态 `--state-correct/partial/wrong`），组件样式中不再直接写 Tailwind 色值。
- **图标**：`app/components/common/Icon.tsx` 提供统一的线性 SVG 图标，界面中不使用 emoji 作为图标。
- **响应式**：六档断点 375 / 480 / 600 / 768 / 900 / 1120，CSS 统一使用范围语法（如 `(width <= 768px)`），TS 端从 `app/lib/breakpoints.ts` 读取同一组数值。
  - 桌面（> 900px）：左侧导航栏 + 页面标题。
  - 平板（600–900px）：顶部 4 个标签（进度 / 冲刺 / 今日 / 课表），页面标题仅供读屏，样式集中在 `app/tablet.css`。
  - 手机（≤ 600px）：顶部 3 个标签（进度 / 冲刺 / 今日），课表与设置收在「⋯」菜单中。
- 设计细节与已裁定事项见 [`docs/UI_STATUS.md`](docs/UI_STATUS.md)。

## 功能模块

### 1. 学习进度

以 **书目 → 章节 → 小节** 三层大纲为骨架，覆盖 408 四科（数据结构、计算机组成原理、操作系统、计算机网络）与数学三科（高等数学、线性代数、概率论与数理统计）。

- **新学按小节、复习按整章**：分别记录计划日期、完成状态与完成日期；打卡自动填入当天日期，日期可原地修改。标记整章复习前须先完成本章全部小节的新学。
- **排期**：单节 / 整章原地改计划；整章批量排期（统一日期或按天均分）；按章或按科目整体前移 / 后移 N 天；变更前预览受影响小节，可一次撤销并保留修改历史。
- **当前学习**：任意未完成小节可设为「当前学习」并置顶高亮。
- **本周节奏**：概览本周计划与完成情况。
- **目录筛选**：全部 / 未学 / 未复习 / 逾期，支持一键展开或折叠。
- **小节日志**：小节行显示关联日志数量，可从右侧抽屉查看或新增该小节的日志。
- **旧版数据迁移**：旧版「小节复习」记录会自动折算为整章复习（取最晚的复习日期与计划日期），迁移前保存本地快照。

### 2. 套卷冲刺

- **科目**：408 / 数学 / 英语 / 政治。
- **试卷库**：内置 2010–2026 年真题（政治为 2017–2026 年）；408 与数学可自行添加模拟卷。
- **筛选**：按试卷类型、完成状态筛选，真题按年份正序 / 倒序排列；手机端将筛选收进折叠面板。
- **卡片视图**：每套试卷一张卡片，显示得分、答题卡缩略图、二刷状态与复盘日志入口；手机端卡片默认收起为摘要行。
- **题型答题卡**：
  - 408：1–40 单选（按 DS / CO / OS / CN 分科）+ 41–47 综合题；
  - 数学：1–10 选择、11–16 填空、17–22 解答；
  - 英语：完形、阅读、新题型、翻译与写作。
  - 支持单题切换对错、批量输入错题号（如 `3, 8, 14, 43`）、一键全对、一键清零。
- **错题复盘日志**：从答题卡一键生成包含「考点、错误归因、正解与反思、补强计划」的 Markdown 模板并写入学习日志。
- **二刷追踪**：独立记录二刷完成状态与日期。
- **试卷云盘**：试卷 PDF 存放在私有 Cloudflare R2 桶中，支持上传、预览、下载、删除，并有空间配额控制。

### 3. 今日

- **执行看板**：左侧为当天的复习课表时间线，右侧为「今日任务」（计划日期为今天的新学小节与复习章节）和「逾期任务」（早于今天仍未完成，由远及近排序，可一键改排到今日）。打卡状态与进度目录实时联动。
- **学习日志**：
  - 按自然日分组的时间流；日志可不关联、关联一个或多个小节，或关联某套试卷。
  - Markdown + KaTeX：支持行内 / 块级公式、GFM 表格、代码块、任务列表，长文自动折叠；HTML 走白名单过滤。
  - 编辑器支持「编辑 / 分栏 / 预览」切换（手机端为编辑 / 预览两种模式），并统计字数。
  - 全文搜索（正文、标题、关联小节）+ 7 个筛选：全部 / 重点 / 无关联 / 有关联 / 408 / 数学 / 已发布。
  - **发布到博客**：可将日志发布到 GitHub Pages 博客（`craig9re5.github.io`），发布稿与原日志相互独立，可自定义 slug 并单独润色。

### 4. 复习课表

- 一周课表，按主题着色：408（蓝）、数学强化（绿）、数学常规（石板灰）、英语与政治（珊瑚）、自定义（赭黄）。
- 两种布局：横向时间轴、竖向周课表；可切换周次，点击课程格可修改或调整。
- 「重置默认课表」可恢复默认排课。
- 今日页与课表页共用同一份课表数据，并显示当前或下一节课程。

### 5. 设置

- **日程看板**：初试两天的科目时段与分值；修改初试日期后，全站倒计时同步更新。
- **数据管理与本地备份**：导出 / 导入完整 JSON（导入时校验结构并自动修复）；在导入前、恢复前、版本升级前自动创建快照，也可手动创建，最多保留 15 份，可恢复或删除。
- **危险操作**：独立卡片，提供「清空套卷完成记录」。
- **账号与登录**：退出登录。
- **关于**：版本号与博客地址。

> 数据分析页（打卡热力图、周度趋势、结课预测等）的代码仍保留，但目前由 `app/feature-flags.ts` 中的 `SHOW_DATA_ANALYSIS = false` 关闭；开启后组件和样式按需懒加载。

## 数据同步与安全

- **本地优先 + 云端同步**：数据先写入 LocalStorage，再防抖同步到 Cloudflare D1；日常修改以增量请求提交。
- **版本冲突合并**：客户端提交服务器版本号，版本过旧时服务端返回冲突，客户端以上次同步快照为基准，把本地修改合并到最新云端数据；不同字段的修改同时保留，同一字段并发修改时本地优先。
- **密钥不出 Worker**：GitHub 发布、D1 与 R2 访问都由 Worker 代理，Token 只保存在 Worker Secrets 中。
- **访问码门禁**：分格输入，HttpOnly Cookie，服务端 15 分钟窗口登录限流。

## 快速开始

### 环境要求
Node.js `>= 22.13.0`

### 本地开发与测试

```powershell
# 1. 安装依赖
npm install

# 2. 启动本地开发服务
npm run db:migrate:local
npm run dev

# 3. 运行全套自动化测试
npm run test

# 4. 生产构建与本地预览
npm run build
npm run start
```

### 数据库迁移与边缘部署

```powershell
# 本地 D1 数据库迁移
npm run db:migrate:local

# 首次启用试卷云盘：创建私有 R2 桶（名称需与 wrangler.jsonc 一致）
npx wrangler r2 bucket create study-papers

# 远程 D1 数据库迁移
npm run db:migrate:remote

# 部署至 Cloudflare Workers
npm run deploy
```

博客发布默认只允许 `main` 空间。若需将发布权限授予其他空间，在 Worker 环境中配置 `BLOG_PUBLISH_WORKSPACE_ID`；未配置 `GITHUB_TOKEN` 时接口只做模拟发布。生产部署须先执行数据库迁移（包括同步版本、试卷配额和待删除文件队列表）。R2 临时不可用时，试卷删除会保留待清理记录，并在后续打开云盘时重试；清理成功后释放配额。

```text

├─ page.tsx / layout.tsx       # 入口与全局布局（字体、KaTeX、样式挂载顺序）

├─ study-data.ts               # 核心类型、计算、校验与数据迁移
├─ chapter-review.ts           # 整章复习逻辑
├─ feature-flags.ts            # 功能开关（数据分析页）
├─ data/books.ts               # 408 与数学大纲
├─ components/
│  ├─ common/                  # Icon、EditableDate 等通用组件
│  ├─ journal/                 # 日志编辑器与操作
│  ├─ papers/                  # 试卷云盘（R2）
│  ├─ schedule/                # 复习课表
│  ├─ sprint/                  # 试卷卡片与答题卡
│  ├─ AnalyticsActivity.tsx    # 数据分析（懒加载）
│  └─ markdown-renderer.tsx
├─ lib/                        # 断点、日期、Markdown、试卷云盘客户端
├─ globals.css                 # 设计令牌、断点说明与全局样式
├─ journal.css / schedule.css / sprint.css / paper-netdisk.css / analytics.css
├─ progress-mobile.css / sprint-mobile.css / mobile-density.css / touch.css
└─ tablet.css                  # 600–900px 平板布局（最后加载）
shared/                        # 前后端共用的类型、常量与合并逻辑
worker/                        # Cloudflare Worker：API、鉴权、试卷云盘
migrations/                    # D1 迁移 SQL
designs/                       # 设计稿
docs/                          # 当前 UI 状态文档
public/                        # 静态资源
tests/                         # 单元测试与渲染测试
```

## 部署

推送到 `main` 后，`.github/workflows/deploy.yml` 会依次执行测试、lint、类型检查、构建、远程 D1 迁移，并部署到 Cloudflare Workers。
