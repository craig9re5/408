# 408 学习目录

一个简洁的 408 学习进度页面，当前收录数据结构、计算机组成原理和操作系统三本书的完整目录。

- 在右上角自由切换书籍。
- 点击章节卡片展开小节。
- 每个小节只记录“学完”和“复习一遍”，勾选时自动填写当天日期，也可手动修改。
- 当前学习位置自动指向所选书籍的第一个未学小节。
- 数据结构和计算机组成原理默认标记为已学完并复习过一遍。
- 所有进度保存在浏览器本地存储中。

目录原稿保存在 [`content/目录.md`](content/目录.md)，页面数据维护在 [`app/data/books.ts`](app/data/books.ts)。

## 本地预览

```powershell
npm install
npm run dev
```

## 构建检查
