# 考研备考空间 (Study Dashboard 2.0)

面向计算机 408 统考、考研数学与考研英语全流程备考的轻量沉浸式学习看板与知识沉淀空间。

---

## 🌟 系统定位与设计理念

- **全流程一站式备考工作台**：贯通「基础轮次知识大纲推进 → 每日任务执行与沉淀 → 冲刺套卷全真模考 → 错题归因与复盘日志 → 多维学情数据分析」的完整考研复习闭环。
- **学术人文视觉美学**：采用经典学术人文风格排版（Noto Serif SC 衬线体标题、暖米纸色底色 `--paper: #fbfaf6`、深青墨黑 `--sidebar: #111b24`、珊瑚朱红 `--coral: #ef846d`），纯原生 CSS 精雕细琢，无庞大 UI 库负担，兼顾桌面端侧边栏与移动端底部 Dock 栏。
- **双层存储与边缘多端协同**：本地 LocalStorage 毫秒级持久化响应 + Cloudflare D1 边缘数据库 350ms 防抖同步，辅以基于 ID-level Last-Write-Wins (LWW) 的多设备无损合并机制，离线可用且多端并发不丢记录。

## 📱 五大核心模块功能详述

### 1. 学习进度 (Progress) —— 知识体系与排期规划

作为备考知识点推进的主战场，系统以**书目 → 章节 → 小节**三层大纲树为骨架：

- **项目与科目切换**：
  - 顶部快速切换两大专业大类：`408` 与 `数学`。
  - 完整收录 408 四科（数据结构、计算机组成原理、操作系统、计算机网络）与数学三科（高等数学、线性代数、概率论与数理统计）官方考纲知识点。
- **两阶段打卡体系**：
  - 每个小节独立记录「学完」与「复习一遍」两种状态。
  - 勾选打卡时自动填入当天日期，支持点击原地手动修改日期。
  - **严格的状态前置依赖**：未学完项禁止勾选复习；若取消已复习小节的学完状态，系统弹出二次确认并联动清除复习记录。
  - 章节卡片自动汇总计划起止区间、第一轮与复习完成日期（以该阶段最后完成的小节日期为准）以及完成度百分比徽章（如 `12/12 ✓`）。
- **智能排期与批量调度**：
  - **原地编辑**：单元格点击即刻弹出日历修改单节计划。
  - **批量排期**：支持对整章小节设定起止区间，并提供「统一日期」或「按天均分」智能排期。
  - **计划区间移动**：支持按章节或科目对后续计划进行批量前移/后移（`+N 天` / `-N 天`）。
  - **安全预览与撤销**：排期变更前提供受影响小节对照预览，支持一次撤销，并完整保存计划修改历史。
- **小节专属日志抽屉 (Section Journal Drawer)**：
  - 小节行展示 `📝 N 条记录` 徽章与悬浮 `+ 记` 按钮。
  - 点击即可从屏幕右侧滑出抽屉，专门归档、回顾与回溯该小节专属的学习心得与错题复盘。
- **置顶当前学习小节**：支持将任意未完成小节设为「当前学习」，高亮置顶并全局导航提示，自动定位到首个未学小节。
- **目录多维筛选**：支持「全部 / 未学 / 未复习 / 逾期」四维过滤与一键全展开/折叠。

### 2. 套卷冲刺 (Sprint) —— 真题模考、题型答题卡与学情画像

专为后期模考冲刺打造的做题中枢与诊断中心：

- **真题与模拟试卷库**：
  - 内置 2010 ～ 2026 年历年统考真题库。
  - 支持自定义添加与管理全真模拟试卷（如王道 8 套卷、李林 6 套卷、合工大超越等）。
  - 支持考研英语客观选择题专项与全题型答题卡。
- **双排版视图随心切换**：
  - **📑 分屏表格视图 (Split View)**：左侧高效流式表格管理试卷打卡、得分、答题卡入口、二刷状态与复盘日志；右侧展示冲刺学情画像。
  - **🍱 模块化 Bento 卡片流 (Bento View)**：模块化网格卡片，内嵌可视答题卡微缩热力图、得分、二刷完成标记与复盘日志联动。
- **全真题型答题卡矩阵 (Visual Question Board)**：
  - **科目专属题型结构**：
    - **408**：1～40 题单选题（按数据结构 DS、组成原理 CO、操作系统 OS、计算机网络 CN 精准分科）；41～47 题综合应用大题。
    - **数学**：1～10 题选择题、11～16 题填空题、17～22 题解答题。
    - **英语**：完形填空（0.5分/题）、传统阅读（2分/题）、新题型（2分/题）、英译汉与短文写作主观表达题。
  - **极速录入交互**：单题点击切换对错、文本框批量录入错题号（如 `3, 8, 14, 43` 快速应用）、一键全对、一键清零。
  - **✍ 智能错题复盘日志生成**：点击一键提取当前试卷全部错题号，自动生成包含「考点、错误归因、正解与反思、后续补强计划」的结构化 Markdown 模版并注入学习日志。
- **冲刺学情画像与深度诊断**：
  - **分科/题型正答率诊断**：实时统计四科或各题型的做题加权正答率，采用三级色彩进度条直观呈现知识短板。
  - **模考成绩走势分析**：自动汇总近年模考最高分、平均分与最低分，并绘制直观柱状走势图。
  - **二刷追踪**：支持真题二刷独立打卡与二刷完成日期记录。

### 3. 今日 (Today) —— 每日任务与学习日志时间流

日常高频执行与复盘思考的两屏一体化工作台：

- **首屏：每日执行看板 (Execution Board)**：
  - 顶部展示今日日期、农历与星期徽章，提供 `✍ 写今日记录` 核心入口与 `↓ 学习日志` 锚点平滑跳转。
  - 三栏分类任务清单：
    - `01 今日计划`：计划日期为今天的全部小节列表，支持即时打卡。
    - `02 逾期追赶`：早于今天未完成小节，由远及近智能排序，快速消灭积压。
    - `03 未复习清单`：第一轮已学完但尚未完成复习的小节清单。
  - 任务打卡状态与进度目录实时双向联动。
- **次屏：学习日志时间流 (Journal Timeline Stream)**：
  - **时间轴聚类**：日志按自然日聚合分组（如 `8月14日 · 星期五`），左侧具备时间轴实线与节点。
  - **多级上下文关联**：支持无关联随笔、单/多小节关联、模考试卷关联三种粒度。
  - **Markdown + KaTeX 数学排版引擎**：
    - 完美支持 LaTeX 行内公式（`$O(n \log n)$`）与块级公式（`$$\int_a^b f(x)dx$$`）。
    - 支持 GFM 表格、代码高亮、任务列表与长文优雅折叠。
    - 内置严格的 HTML 标签白名单与 XSS 安全过滤。
  - **分屏实时预览编辑器**：支持桌面端「编辑 / 分栏 / 预览」三模切换、移动端极简双模与实时字数统计。
  - **多维快速检索**：支持全文模糊搜索（正文、标题、关联小节），提供 6 个分类胶囊（全部 / 纯随笔 / 有关联 / 408 / 数学 / 已发布）。
  - **GitHub Blog 一键发布**：直接将精选日志发布到个人公开静态博客（如 `craig9re5.github.io`），发布稿与原日志解耦，支持自定义 URL Slug 与独立润色，发布后展示 Blog 徽章并提供直达外链。

### 4. 数据分析 (Analytics) —— 备考大数据与冲刺预测

基于真实打卡行为大数据的可视化分析中枢：

- **多维统计口径**：支持在「总览」、「408」、「数学」三种统计范围下实时重新计算所有指标。
- **初试倒计时与进度看板**：展示距离初试剩余天数、总小节数、第一轮学完率、第二轮复习率及当前计划覆盖度。
- **14 天学力速率与结课冲刺预测**：
  - 统计近 14 天日均完成小节速率（小节/天）。
  - 依据剩余未学小节数，严谨推导出预计结课日期。
  - 自动评估冲刺阶段可用天数，给出健康度节奏预警（充足 / 稳健 / 紧迫 / 落后）。
- **连续学习天数 (Streak Engine)**：采用「回溯断点探测」算法，自最近一次打卡日起向前逐日追溯，即使早间未打卡也不会发生断连误判。
- **12 周活动热力图 (Activity Heatmap)**：过去 84 天的日历网格，按每日学完与复习量呈现 4 级翡翠绿渐变，悬浮 Tooltip 展示每日明细。
- **周度推进趋势柱状图**：按周对比新学与复习小节量，清晰反映备考状态与周期起伏。

### 5. 设置 (Settings) —— 考程联动与数据安全资产

- **统考初试日程表**：
  - 联动展示初试第一天（政治、英语）与第二天（数学、408）的标准考场时段与分值分布。
  - 修改考研基准日期自动全域同步所有倒计时组件。
- **全量数据导出与导入迁移**：
  - 导出包含两项目全部小节状态、计划编排、设置、历史、学习日志与模考记录的标准 JSON。
  - 导入时执行严格的 Schema 校验与逻辑修复自愈。
- **多版本本地快照与容灾机制**：
  - 系统在「导入前」、「恢复前」、「版本升级前」自动创建本地快照。
  - 支持手动随时创建快照，按时间倒序最多保留 15 份，支持一键恢复与单份清理。
- **关于与博客配置**：展示当前系统版本号与个人博客站点。

## 🔒 数据同步与安全机制

- **零秘钥泄露架构**：所有外部调用（如 GitHub API 发布文章）与数据库访问均由 Cloudflare Worker Serverless 网关代理，私密 Token 仅保存在 Worker 环境变量 Secrets 中，前端绝不接触鉴权密钥。
- **6 位数字 OTP 安全门禁**：进入系统需输入 6 位访问码，提供分格输入体验、HttpOnly 安全 Cookie 与常量时间比对防时序攻击。
- **多设备无损合并 (ID-level LWW Merge)**：
  - 多端并发或离线创建日志/试卷记录时，以 ID 全集联合 + `updatedAt` 时间戳进行合并，保证两端新建记录完整保留。
  - 客户端通过墓碑队列显式上报主动删除的记录 ID，Worker 在持久化前精确剔除，杜绝已删除项被错误复活。

## 🛠️ 技术栈

- **前端框架**：Next.js (React 19) + TypeScript
- **构建工具链**：Vinext / Vite 8 + Tailwind CSS
- **数学公式与富文本**：KaTeX + Marked
- **边缘计算与数据库**：Cloudflare Workers + Cloudflare D1 (SQLite) + Drizzle ORM
- **本地存储与快照**：LocalStorage 本地双写与多版本快照容灾层

## 🚀 快速开始

### 环境要求
Node.js `>= 22.13.0`

### 本地开发与测试

```powershell
# 1. 安装依赖
npm install

# 2. 启动本地开发服务
npm run dev

# 3. 运行全套自动化测试
npm run test

# 4. 生产构建与本地预览
npm run build
npm run start
```

### 数据库迁移与边缘部署

```powershell
# 本地 D1 数据库迁移
npm run db:migrate:local

# 远程 D1 数据库迁移
npm run db:migrate:remote

# 部署至 Cloudflare Workers
npm run deploy
```
